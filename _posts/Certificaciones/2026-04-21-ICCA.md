## ¿Cómo es el examen?

El examen de la certificación **ICCA** tiene una duración de 1 hora y media y consta de 46 preguntas tipo test junto con 4 objetivos prácticos en laboratorio. Evalúa conceptos fundamentales de computación en la nube y el uso de plataformas como Amazon Web Services, Microsoft Azure y Google Cloud Platform. Incluye temas como modelos de servicio (**IaaS, PaaS, SaaS**), redes, almacenamiento, seguridad e identidades, además de requerir que comprendas cómo crear y gestionar recursos básicos como máquinas virtuales, almacenamiento y configuraciones de acceso.

## Material de estudio

Para poder dar el examen usé el recurso que ofrece **INE**, que son casi 16 horas de material organizadas en módulos y algunos laboratorios. Si quieres dar esta certificación y no sabes nada de la nube, considero que este recurso es muy bueno explicando desde cero: cómo funciona la arquitectura cloud, los 3 proveedores principales como **Amazon Web Services**, **Microsoft Azure** y **Google Cloud Platform**, además de temas clave como modelos de servicio **(IaaS, PaaS, SaaS)**, redes, almacenamiento, gestión de identidades (**IAM**), seguridad y cumplimiento. El contenido es bastante progresivo, va de lo básico a lo más aplicado, con ejemplos claros en cada plataforma. No es súper práctico, pero sí te deja con una buena base para entender cómo funcionan los servicios en la nube y cómo usarlos en escenarios reales.

## Conocimientos que debes dominar antes de rendirlo

En los laboratorios del examen **ICCA** no solo te preguntan teoría, sino que debes demostrar que sabes usar la nube en la práctica. Es decir, debes saber realizar tareas básicas de configuración y gestión de recursos.

### 🔧 Tareas típicas que debes saber hacer

- **Crear recursos en la nube**
    - Crear una máquina virtual (EC2 en AWS / VM en Azure / Compute Engine en GCP)
    - Configurar sistema operativo, región y tamaño

- **Almacenamiento**
    - Crear un bucket (S3 en AWS / Storage Account en Azure / Cloud Storage en GCP)
    - Subir y descargar archivos
    - Configurar permisos (público o privado)

- **Redes**
    - Crear una red virtual (VPC / VNet)
    - Crear subredes
    - Configurar reglas de acceso:
        - Security Groups (AWS) / NSG (Azure)
        - Permitir o bloquear puertos (ej: SSH, HTTP)

- **Gestión de identidades (IAM)**
    - Crear usuarios
    - Crear roles o políticas
    - Asignar permisos a recursos (ej: acceso a un bucket o VM)

- **Acceso a recursos**
    - Conectarte a una VM (por SSH o RDP)
    - Usar claves o credenciales correctamente

- **Uso de consola, CLI o Cloud Shell**
    - Ejecutar comandos básicos como:
        - listar instancias
        - ver recursos creados
    - Entender diferencias entre consola web y línea de comandos

- **Monitoreo básico**
    - Ver métricas o logs (CloudWatch en AWS)
    - Identificar si un recurso está activo o detenido

- **Configuración de seguridad básica**
    - No dejar recursos públicos innecesariamente
    - Aplicar buenas prácticas de acceso
    - Entender errores comunes de configuración
